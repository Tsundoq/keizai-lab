# 品質ゲート / リグレッションチェック

## 制作前
- [ ] 既存の画面とコードを読み、維持する要素を挙げた
- [ ] 変更対象・変更禁止箇所・完成条件を定義した
- [ ] 参考資料の出典や仕様と、実際の実装制約を区別した

## 操作
- [ ] グラフにポインター / タッチで予想を書ける
- [ ] 予想を確定し結果を表示できる
- [ ] リセットで初期状態に戻れる
- [ ] シェア / コピーは期待どおりに機能する（ブラウザ制限があれば記録）
- [ ] 複数回操作しても操作不能・状態不整合にならない

## 見た目・アクセシビリティ
- [ ] 360px前後の縦長スマートフォン表示で横スクロール・切れ・重なりがない
- [ ] デスクトップでもグラフ・本文の余白、文字サイズが破綻しない
- [ ] `:root` の既存デザイントークンと書体を維持している
- [ ] タップ領域、フォーカス表示、コントラスト、縮小表示を確認
- [ ] 可能なら最初の画面、入力後、結果表示のスクリーンショットを見比べた

## 技術・内容
- [ ] JavaScriptエラー、リソース読み込み失敗がない
- [ ] データ・注記・数字・単位・出典を勝手に変更していない
- [ ] 新しい依存関係・設定ファイルを不要に増やしていない
- [ ] 既存動作の後退がない

## 報告
- [ ] 実施したテストと結果を具体的に報告
- [ ] 未実施の検証は「未検証」と明記
- [ ] 差分がある場合、次に改善する箇所を具体的に記載
